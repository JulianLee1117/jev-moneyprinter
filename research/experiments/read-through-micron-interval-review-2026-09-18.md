# Micron intervening-source census

The six registered historical intervals now have a complete extraction of their **currently indexed English-language issuer news bodies and event metadata**. This improves the prior-state inputs substantially, but does not complete historical guidance reconciliation: each interval contains an investor conference whose substantive discussion remains uncollected, and earnings Q&A/post-earnings calls are still missing.

The canonical local inventory is `data/readthrough-financial-v1/micron-intervening/micron-intervening-census.v1.json`. Each news body has a separate hash-bound JSON file containing the complete source HTML and deterministically extracted text. Every interval lists all sources, including sources with zero navigation matches, and preserves same-day boundary records separately. The inventory contains no model labels, trade signals or prices.

The site's linked public Q4 widget JavaScript documents the news/event feed endpoints and parameters. Requests used English language, each entire year, no category/tag restriction, full news bodies and the widget's `pageSize=-1` all-items setting. The captured feeds returned 41/39/38 news records and 12/12/10 event records for 2024/2025/2026 respectively. All returned record IDs were preserved; no search engine or content filter selected the source population. This describes the current feed response, not removed or historically unlisted material.

There are **57 news bodies strictly between the six pairs of earnings dates**, plus the seven boundary earnings releases. The six intervals contain 11, 9, 7, 8, 10 and 12 interior news items respectively. Each has one indexed interior investor conference. Literal searches for capex, capital expenditures/spending, WFE or wafer-fabrication equipment returned zero matches in the interior news bodies across all six intervals. That zero is a lexical observation, not an unchanged-guidance label; the complete source text remains available.
